Static robot joint torque calculator

Enter comma-separated values, one per link. Lengths are metres and masses kilograms. The browser form uses relative angles in degrees and converts them to radians. Centers of mass are at each link midpoint in this form; the Python API supports custom COM fractions.

Check the examples

Angles 0, 0: shoulder 5.3955 N m, elbow 1.2753 N m. Angles 0, 180: shoulder 2.8449 N m, elbow -1.2753 N m. Angles 90, 0: both approach zero.

Positive output is counterclockwise holding torque. This is a static ideal model, not a motor-sizing recommendation or hardware safety check. It omits acceleration, friction, gearbox losses and thermal limits. Do not connect it to a powered robot.
